NVIDIA NeMo Agent Toolkit: ReAct agent stops on truncated LLM output (merged Oct 30, 2026)
The ReAct agent never checked the LLM's finish_reason, so a reply cut off at max_tokens was parsed as if it were complete: a truncated "Final Answer" came back as the result, and a truncated "Action Input" was passed straight to a tool (#2518). The agent node now raises a clear RuntimeError when the response finishes with finish_reason "length", matching what the tool-calling agent already did, and the check covers both the first call and calls inside the tool loop. Two regression tests (first call and mid-loop, asserting no tool runs) fail on develop and pass with the fix; the 177-test ReAct suite passes. Approved by maintainer willkill07. https://github.com/NVIDIA/NeMo-Agent-Toolkit/pull/2519
