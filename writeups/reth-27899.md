# Skipping the JWT secret when reth's auth server is off

Problem: in reth, Paradigm's Ethereum node, starting with `--disable-auth-server` still loaded or created a JWT secret file, which caused needless disk writes and a startup failure when a configured secret path was missing (issue #27867). Fix: the launcher skips that filesystem access when the auth server is disabled and uses an in-memory random secret instead, keeping the existing `AddOnsContext` API, with a launch regression test covering both the default and a missing explicit path. Result: merged on Oct 15, 2026. [PR #27899](https://github.com/paradigmxyz/reth/pull/27899)
